# ورودی‌های فاز دوم

چهار ورودی مجاز تیم درس را در data/raw بگذارید: amarpr.pdf، udslong_imputed.csv، mriscanclean.csv و combined_adjacency_matrix.csv. طبق دستورالعمل استاد، دادهٔ خام داخل ZIP قرار ندارد.

نام دقیق، اندازه و SHA-256 ورودی‌های اجرا در tables/p2_01_inputs.csv ثبت شده‌اند. پیشوند عددی و پسوندی مانند (9) پذیرفته می‌شود؛ دو نسخهٔ هم‌نام موجب توقف است. تاریخ دریافت اولیه از NACC و فرایند جایگذاری/آماده‌سازی اولیه موجود نیست. هیچ دادهٔ بیرونی به تحلیل اضافه نشده است.

اثر انگشت ورودی‌ها و مقادیر کنترل بازتولید در docs/phase2_reference.json ذخیره شده‌اند. اتصال UDS و MRI با NACCID و کنترل یکتایی انجام می‌شود؛ ماتریس مجاورت ناحیه‌ای وارد اتصال فردی نمی‌شود.
