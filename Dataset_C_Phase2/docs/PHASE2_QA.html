کنترل کیفیت فاز دوم

  • بسته شامل گزارش، نوتبوک اجراشده، کد، جدول‌ها، نمودارها، فونت و مستندات فاز دوم است.
  • زنجیرهٔ تحلیل و همهٔ سلول‌های نوتبوک اجرا شده‌اند. احتمال‌ها و ممان‌ها با بازشماری مستقل و هویت‌های ریاضی کنترل می‌شوند.
  • اثر انگشت ورودی‌ها و مقادیر کنترل بازتولید در phase2_reference.json ثبت شده‌اند. قواعد اعتبار، نمونهٔ تحلیلی و همهٔ نتایج عددی حفظ شده‌اند.
  • گزارش فارسی با فونت B Nazanin و قالب سیاه‌وسفید تهیه شده است. عنوان نمونه در جدول جریان داده «نمونهٔ اصلی» است.
  • کنترل خروجی‌ها، احتمال‌ها، نوتبوک، PDF و پیوندهای HTML با فرمان python src/phase2_validate.py انجام می‌شود؛ نتیجه در phase2_qa.json ثبت می‌شود.
  • برچسب محلی phase-2 در بستهٔ Git موجود است. انتشار GitHub و ارسال CW در این جلسه انجام نشده‌اند. دادهٔ خام مطابق دستورالعمل استاد در ZIP قرار ندارد.
