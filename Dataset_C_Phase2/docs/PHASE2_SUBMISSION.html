اجرا و تحویل فاز دوم

این ZIP فقط فاز دوم را شامل می‌شود. از README.html شروع کنید؛ مسیر الزامی گزارش reports/phase2.pdf است. پنج شکل PNG/SVG، جدول‌های تجمیعی، نوتبوک اجراشده، فونت و کد لازم در همین بسته قرار دارند.

بازتولید

python -m pip install -r requirements.txt
python src/phase2_analysis.py --data-dir data/raw --execute-notebook
python src/phase2_validate.py

چهار فایل ورودی را مطابق data/README در data/raw قرار دهید یا مسیر مجاز دیگر را با --data-dir مشخص کنید. برای خروجی جدا از --out-dir با پوشهٔ خالی استفاده کنید. کد و فایل‌های لازم برای اجرای تحلیل در همین بسته قرار دارند. نصب PDF در Linux به Pango وابسته است؛ نمونهٔ Debian/Ubuntu: sudo apt install libpango-1.0-0 libpangoft2-1.0-0 fonts-dejavu-core. با --skip-pdf و بدون --execute-notebook، خروجی عددی و منبع گزارش ساخته می‌شود. نوتبوک در سلول آخر PDF را نیز می‌سازد.

برچسب و تحویل

بستهٔ محلی phase2_git.bundle فقط همین فاز دوم را در بر دارد و برچسب phase-2 دارد. این یک تصویر از تحویل مستقل فعلی است و جای تاریخچهٔ واقعی مخزن اصلی را نمی‌گیرد. برای مشاهده:

git clone docs/phase2_git.bundle ../Phase2_Repository
git -C ../Phase2_Repository tag --list

برای تحویل رسمی، همین مواد را در مخزن واقعی پروژه ثبت کنید و برچسب phase-2 را مطابق وضعیت مخزن منتشر کنید؛ تاریخچهٔ قبلی را جایگزین نکنید. ZIP باید در CW نیز بارگذاری شود. هیچ انتشار یا ارسال بیرونی در این جلسه انجام نشده است. تکمیل نه تکلیف مشترک و پنج تکلیف مسیر ج در سند پوشش آمده است.

روش جایگذاری، تاریخچهٔ مراجعه و انطباق زمانی اسکن در ورودی‌ها نامعلوم‌اند؛ این موارد در گزارش مستند شده‌اند. مطابق داک، انجام فردی و توانایی دفاع باید رعایت شود؛ فایل‌ها ادعای انجام مستقل مراحل دریافت‌شده توسط دانشجو نمی‌کنند.
