# فاز اول آمار — Dataset C: NACC UDS + MRI

این بسته شامل تحلیل توصیفی اجراشده، گزارش فارسی، پنج شکل PNG و SVG، جدول‌های تجمیعی، نوتبوک اجراشده، فرهنگ منتخب، موجودی همهٔ ستون‌ها و راهنمای دفاع است. سؤال دقیق و قواعد در PROJECT_CARD.md آمده‌اند. فقط فاز اول انجام شده است.

## اجرای بازتولید

Python 3.11 یا بالاتر پیشنهاد می‌شود. روی Linux برای PDF به Pango و فونت DejaVu Sans نیاز است؛ نصب سیستم‌عامل نمونه در Debian/Ubuntu: `sudo apt install libpango-1.0-0 libpangoft2-1.0-0 fonts-dejavu-core`. مستندات نصب WeasyPrint برای سیستم‌عامل دیگر را ببینید. با نبود قابلیت PDF، مسیر `--skip-pdf` آمار، شکل و منبع گزارش را بازتولید می‌کند.

نوتبوک در این محیط با اجرای واقعی و متوالی سلول‌ها در IPython و ثبت خروجی‌ها اجرا شده است؛ برای اجرای دوباره به ارتباط شبکه‌ای کرنل نیاز ندارد.

از ریشهٔ بسته:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/run.py --data-dir data/raw --execute-notebook
```

چهار فایل مجاز را در `data/raw/` قرار دهید: `amarpr.pdf`, `udslong_imputed.csv`, `mriscanclean.csv`, `combined_adjacency_matrix.csv`. کد پسوندهایی مانند `(7)` و پیشوند `01-` را می‌پذیرد، اما اگر چند نسخهٔ هم‌نام موجود باشد متوقف می‌شود. ورودی‌ها هیچ‌گاه بازنویسی نمی‌شوند. مسیر دیگر را با `--data-dir /path/to/authorized/files` مشخص کنید. این مسیر تنظیمی است و هیچ داده‌ای دانلود نمی‌شود.

برای خروجی مستقل و پاک:

```bash
python src/run.py --data-dir data/raw --out-dir ../phase1_clean --execute-notebook
```

برای اجرای جداگانهٔ نوتبوک، متغیر محیطی `NACC_DATA_DIR` را روی پوشهٔ ورودی بگذارید و از ریشهٔ بسته یا پوشهٔ notebooks اجرا کنید. مسیر دادهٔ استفاده‌شده در این جلسه در کد نوتبوک سخت‌نویسی نشده است. فایل `src/execute_notebook.py` اجرای بدون رابط را فراهم می‌کند.

## فایل‌ها و ترتیب محاسبه

- `src/definitions.py`: تعاریف، اعتبار متغیرها و شاخص دوطرفه.
- `src/analysis.py`: ممیزی، اتصال، جریان افراد و جدول‌های تجمیعی.
- `src/plots.py`: پنج نمودار، همگی در یک نمونهٔ اصلی مشترک.
- `src/report.py`: گزارش فارسی و تبدیل به PDF؛ متن قابل ویرایش در `reports/phase1.md` و HTML.
- `src/documentation.py`: کارت، راهنماها و پوشش الزامات.
- `src/run.py`: اجرای کل زنجیره؛ خروجی پیش‌فرض ریشهٔ بسته است.
- `notebooks/phase1_executed.ipynb`: توضیح فارسی همراه خروجی اجراشده.
- `tables/07_overall.csv` و `08_by_group.csv`: جمعیت اصلی، دسترسی متغیر به متغیر و تکمیلی مشروط با برچسب جدا.
- `docs/qa_analysis.json`, `docs/QA_DELIVERY.md`: کنترل‌های تحلیلی و تحویل.

آمارهای اصلی روی MoCA صحیح ۰ تا ۳۰ محاسبه می‌شود. اعشار داخل دامنه بدون گردکردن فقط در خلاصهٔ تکمیلیِ مشروط حفظ می‌شوند؛ کد ۸۸ و مقادیر خارج دامنه نمره نیستند. هیچ جایگذاری جدید، حذف IQR، آزمون فرض، p-value، فاصلهٔ اطمینان، رگرسیون یا یادگیری ماشین اجرا نشده است. تمام خروجی‌ها تجمیعی‌اند؛ فایل تحلیلی فردی ذخیره نمی‌شود.

## وضعیت اطلاعات و اقدام‌های باقی‌مانده

فرهنگ اختصاصی و دستورالعمل آماده‌سازیِ وعده‌داده‌شده در PDF استاد موجود نبود. تعاریف با مستندات عمومی NACC تطبیق یافتند؛ منشأ اعشار، روش جایگذاری، تاریخ‌ها و انطباق زمانی حل‌نشده‌اند. شمار تاریخی مراجعات قابل محاسبه نیست. گزارش، این موارد را پنهان نمی‌کند. جدول تکمیلی اعشاری مشروط است.
