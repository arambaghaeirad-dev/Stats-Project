تحویل فاز اول و نکته‌های دستورالعمل

دستورالعمل استاد مرجع اصلی است. فاز اول از ۱۸ مهر تا ۱۲ آبان ۱۴۰۵، با ۱۲٫۵ امتیاز پایه از ۱۰۰، تعریف شده است. سقف ۱۱۰ مربوط به کل مسیر ج و انجام صحیح الزامات چندوجهی کل پروژه است؛ امتیاز تضمین نمی‌شود. مهلت قطعی اعلام شده و تغییرات کانال رسمی درس باید توسط دانشجو پیگیری شود.

خروجی دقیق اعلام‌شده در صفحهٔ ۸: reports/phase1.pdf، PROJECT_CARD.md، کد قابل بازتولید، README به‌روز و برچسب phase-1. مسیر دقیق PDF رعایت شده است؛ در بخش ساختار پیشنهادی صفحات ۱۸–۱۹ پوشهٔ reports/phase1/ نیز آمده، ولی الزام خروجی صریح صفحهٔ ۸ مبنا قرار گرفت. پنج شکل از حداقل چهار شکل بیشتر است؛ ده تسک مشترک، آزمون فرض نیستند.

GitHub مرجع اصلی بررسی و تاریخچه است. فایل‌ها را پس از بازبینی و اجرای شخصی در مخزن خود قرار دهید. دادهٔ خام، شناسهٔ فردی، فایل فردی پردازش‌شده، رمز و کش را اضافه نکنید. تاریخچه باید واقعی باشد؛ commit ساختگی یا با تاریخ گذشته نسازید. انجام کل کار در یک commit پایانی در سند استاد روند مناسب تلقی نشده است. این بسته تاریخچهٔ گذشته ایجاد نمی‌کند؛ مراحل واقعی بازبینی و اصلاح خود را از اکنون ثبت کنید.

پس از نهایی‌شدن و commit واقعی در مخزن موجود، دستورات نمونهٔ زیر را اجرا کنید؛ این‌ها در این جلسه اجرا نشده‌اند:

git status
git add README.md PROJECT_CARD.md requirements.txt .gitignore src notebooks tables figures reports docs data/README.md
git diff --cached --stat
git commit -m "Complete reviewed Phase 1 descriptive analysis"
git tag -a phase-1 -m "Phase 1: NACC UDS and MRI descriptive analysis"
git push origin HEAD
git push origin phase-1

پیش از tag، نبودن داده و شناسه و اطلاعات محرمانه در فایل‌های stage را بازبینی کنید. اگر phase-1 موجود است آن را بدون بررسی جابه‌جا نکنید. لینک مخزن و نحوهٔ دسترسی تیم ارزیاب باید طبق اعلام رسمی درس تنظیم شود؛ لینک ساختگی ارائه نشده است.

در CW نیز ZIP شامل PDF، کد، نوتبوک، شکل‌ها، راهنماها و خروجی‌ها بارگذاری شود؛ CW جایگزین GitHub نیست. ZIP این بسته برای این مرحله آماده است، اما بارگذاری، ساخت مخزن و tag انجام نشده‌اند. نام و شمارهٔ دانشجویی مطابق اطلاعات ارائه‌شده درج شده‌اند؛ مشخصات دانشگاه و استاد ساخته نشده است. قالب نام فایل تحویل، ساعت دقیق ددلاین و مشخصات درس/استاد در اطلاعات دریافت‌شده تعیین نشده‌اند.

تفاوت با درخواست و اقدام‌های حل‌نشده

سند رسمی (ص۱ و ۱۹) انتخاب سؤال، کدنویسی، تحلیل، نوشتن و دفاع را فردی و توسط خود دانشجو می‌خواهد. این بسته خروجی کمکی قابل بررسی است و ادعای انجام مستقل دانشجو نمی‌کند. در سند، الزام صریح و جداگانه‌ای برای عبارت افشای هوش مصنوعی دیده نشد؛ بااین‌حال نباید سهم کمک دریافت‌شده خلاف واقع معرفی شود و لازم است مجازبودن نحوهٔ استفاده طبق مقررات واقعی درس روشن باشد. گزارش با عنوان دانشگاهی آغاز شده است.

فرهنگ اختصاصی، کلیدهای مراجعه و روش آماده‌سازی که در سند وعده داده شده، در چهار پیوست نبود. اتصال فردی بر اساس یکتایی NACCID قابل دفاع و کنترل‌شده است؛ اتصال زمانی قابل تأیید نیست. اعشار MoCA در تحلیل اصلی کنار گذاشته و در توصیف تکمیلی مشروط حفظ شده‌اند. از تیم درس باید روش جایگذاری، وضعیت اعشار، قاعدهٔ انتخاب مراجعه و واحد/پردازش نهایی MRI تأیید شود؛ شمارش تاریخی مراجعات از این فایل‌ها قابل بازیابی نیست.
